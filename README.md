# NTK 확장 저장소

Tachimanga, Mihon, Komikku 계열 앱에서 사용할 수 있는 개인용 한국어 확장 저장소입니다.

## 저장소 주소

아래 주소 하나를 등록하면 이 저장소의 확장앱을 설치하고 업데이트할 수 있습니다.

```text
https://raw.githubusercontent.com/wankyo83/ntk-fix/main/index.min.json
```

## 주요 확장

- Newtoki: 웹툰
- ntk manga_v1: 만화
- Toki / DC_Toki: 웹툰 및 만화
- Black toon: 웹툰
- Jjaptoon webtoon: 웹툰
- SBXH: 웹툰 및 만화
- 11toon manga: 만화
- WFWF: 웹툰 및 만화
- dc_naver webtoon: 네이버 웹툰·베스트 도전·도전만화 통합 검색

## dc_naver webtoon

- 흰색 바탕의 초록 토끼 `N` 아이콘
- 확장 목록에는 `dc_naver webtoon` 하나만 표시
- 네이버 웹툰, 베스트 도전, 도전만화 통합 검색
- 구분, 요일, 장르, 연재 중/완결, 정렬 필터
- Android용 APK와 iOS Tachimanga 변환 호환성을 확인한 DEX 035 빌드

## 설치 방법

1. 앱의 확장 저장소 설정을 엽니다.
2. 위 `index.min.json` 주소를 추가합니다.
3. 저장소를 새로고침합니다.
4. 원하는 확장을 설치하거나 업데이트합니다.

목록이 이전 상태로 보이면 앱을 완전히 종료한 뒤 저장소를 다시 새로고침하세요.

이 프로젝트는 Tachimanga, Mihon, Tachiyomi 또는 각 대상 사이트와 제휴하지 않은 개인용 수정본입니다.
